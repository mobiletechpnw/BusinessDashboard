You're logging numbers by hand — reliable and zero setup. To pull follower counts automatically, connect the Instagram Graph API through a small serverless endpoint (scaffolded in this repo).

How the automated sync works & how to turn it on
Because this dashboard is static (no server), a browser can't safely hold an Instagram token. The included api/instagram-followers.js serverless function holds the token server-side, calls the Graph API, and returns just the numbers. Turn it on with:
  1. Convert your account to Business/Creator and link it to a Facebook Page (your current gap).
  2. Create a Meta Developer app and get a long-lived token with instagram_manage_insights.
  3. Deploy the function to Vercel with the token as an env var.
  4. Paste the deployed URL into Configure endpoint above.
Full walkthrough: docs/INSTAGRAM_SETUP.md.
